# Fish Hats

Put Christmas hats on the fish in your aquarium. Open the page on a phone mounted against the tank glass.

- Open the page and tap **Start camera**. Keep the phone still while it learns the tank.
- Tap the screen for settings. Use **Mask bubbles / filter** to ignore bubbles, filter flow and waving plants.
- Add `#demo` to the address to try it on a pretend tank.
